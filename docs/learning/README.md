# Learning Notes (Project Docs)

Carpeta pública para documentar aprendizajes técnicos por día en formato reutilizable para:

- onboarding
- README/blog
- preparación de demos o entrevistas

## Convención

- Un archivo por día: `YYYY-MM-DD.md`
- Redacción breve y compartible (sin secretos ni notas internas)

## Estructura sugerida

1. Context
2. Key Decisions
3. Technologies Used
4. Concepts Reinforced
5. How to Explain This Work
6. Next Steps
